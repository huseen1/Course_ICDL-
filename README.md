# Course_ICDL-
دورة تفاعلية بالعربية في ملف HTML واحد، تغطي مبادئ الحاسوب وMicrosoft Word وExcel وPowerPoint. تشمل شروحاً نظرية مفصلة، وأمثلة عملية، وتمارين خطوة بخطوة، وقسماً للأخطاء الشائعة، ومسرداً لأهم المصطلحات الإنجليزية مع ترجمتها، واختبارات قصيرة لكل محور، واختباراً نهائياً بمؤقت يحاكي الامتحان. لا تحتاج إلى تثبيت أو خادم، يكفي فتح الملف في المتصفح.
